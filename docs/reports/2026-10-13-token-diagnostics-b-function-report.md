## 当前已验证能力

- SWE 在实际 prepared 请求和操作边界非阻塞记录有界 Context、来源实例及有序 HMAC 块，不保存正文。缺密钥、媒体、大输入、超时及队列满保留明确缺口；真实 Usage 独立记录，摘要调用独立记账。
- 全量初始 DDL 为 24 张类型化关系表，无数据库禁用类型、外键或自动 DDL。Context/操作原子保存，评估历史不可变，head 和替换链按分支隔离。仅面向尚未建表部署。
- Monitor 使用一致快照、租约及输入修订保护执行 R01–R08；前缀为 24h 同组已结束历史、最多 100 候选、有序文本字节区间。下界看板比例与上界规则判定分开。
- 查询区分物理请求窗口、根 Task 窗口与生命周期。全局 aggregate 不取当前页替代；未知不转成 0，部分采集/缺分支/过期/失败/历史结果明确展示。
- 11 个 v2 GET 端点沿用认证 source/tenant/user，不因 admin 或客户端游标扩大范围。A 入口及事件 1.0 保留，新 B 事件 1.1 可读。
- Token 总览读取窗口用量、Task 分布、Agent 归属、八规则覆盖和保守前缀比例，区分未知与零。三个导航入口和旧 A 保留；执行入口无 Task 时实际滚动、聚焦任务列表。总览已通过真实 iframe 四种宽度验证。
- 执行详情展示真实 Task/branch/Call、Context 来源、文本前缀上下界、规则实例和操作前后证据。三次调用切换更新所有关联数据，第三次缺输出保持未知；摘要调用 Usage 独立展示。跨 Task/branch、历史修订及操作归属不匹配时拒绝绑定其他证据。
- 问题页按可信签名聚合，否则逐实例展示。问题组与实例独立分页，评估单独加载并校验身份；建议包含阈值/版本、前提、例外、风险和验证步骤。候选且当前、证据未过期的实例才能打开其真实执行详情；返回保留原窗口、筛选、分页、组及实例。缺失 URL 定位显示明确提示。
- 三页面实际 iframe 完整流程、1280/1440/1920/600 宽度、键盘选择与长实例标识已验收。覆盖服务 503 保留可用问题组、不给零覆盖；问题服务 503 不显示空问题。过期/历史实例保留只读详情并关闭执行跳转。
