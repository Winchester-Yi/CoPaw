# 定时任务回检实施计划

依据 [详细设计](../../plans/2026-11-09-001-feat-cron-recheck-plan.md)，在 `codex/cron-task-tracking` 实施。

1. 配置契约。为 Scheduler 定义、SWE 模型和 Console 编辑器增加可选回检规则。先验证缺省、清除、非法范围和旧客户端更新，再接入保存和展示。
2. 共库生命周期。人工 SQL 建立活动表。在 SWE 完成事务内按父执行唯一键登记，验证成功起算、重复完成和停用竞态。Scheduler 用独立扫描循环领取到期任务并取消失效记录。SWE 使用同会话的执行锁和独立执行键执行，终态回执与活动行删除同事务提交。验证未知派发、忙会话退避和已启动后的恢复。
3. 查询和 Console。先验证当前与历史分页、权限和终态转移，再接入新版定时任务管理页两个回检视图。
4. 验证。用项目虚拟环境执行各切片 pytest，运行 Console Vitest、类型检查和受影响页面验收。覆盖当前浏览器、Chromium 108 及嵌入模式。复核从主执行 A 的成功到原会话回检和历史记录的完整链路。

顺序为配置与共库契约先行，随后接通 SWE 和 Scheduler，最后验收查询与页面。业务数据表通过人工 DDL 交付。
