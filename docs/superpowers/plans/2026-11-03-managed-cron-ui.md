# 新版定时任务管理页整理

在当前 codex/cron-task-tracking worktree 主线程按 TDD 执行，不派发子代理，不修改旧页面、后端或业务语义。

## 已确认范围

列表固定 8 列：任务（名称和 ID，完整 hover 与独立复制）、可执行日期、执行时间、当前调度状态、调度方式、管理状态、最近执行结果、操作。技术字段保留在设置中；日期和人工开关不同，调度状态多个限制逐行显示，问号解释。管理状态中文加原码 hover。结果 hover 同时包含北京时间及失败详情。

更多菜单以任务设置开头，父任务保留分发、子任务管理、进度、整组暂停、删除并分组；子任务仅任务设置、进度、删除。独立日期/模式菜单移除。设置抽屉包含基本配置及调度设置；父任务有子任务时正文只读、日期仍可改；子任务继承日期和模式只读。日期单独变化只调用既有日期接口，其余走既有普通更新。既有模式/优先配置保存分别沿用现有协议，不伪造统一事务。未保存内容关闭/切页需提示。

## 实现与验证记录

- 列测试 RED：旧实现返回 26 列而非 8 列；父任务编辑测试 RED：已有子任务时正文仍可编辑。实现后通过。
- 保存分流按用户的实际字段编辑记录判断，避免隐藏字段注册或时间/日期对象误判；新版转换器不再把 runDates 表单对象混入任务定义。日期单独修改走既有版本化日期接口，内容和日期一起改只发送一次普通更新。
