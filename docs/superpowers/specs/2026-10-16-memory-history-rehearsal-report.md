## 脱敏和隔离

正文字符串遮蔽；标识及动态字典键使用单次运行的随机 HMAC 映射；消息 ID 与引用保持绑定，合法 UUID 保持 UUID 形状。保留协议枚举和必要结构计数，其他数字置为同类型零；合法时间戳归一化，无法完整解析的时间字符串整体遮蔽，不保留尾部文本。

输出目录必须是全新目录，且位于源目录之外；目录权限 0700、准备文件 0600。输入拒绝符号链接、重复 JSON key、非有限数字、非法结构和非规范 chat UUID，不把损坏输入修复成可通过的数据。每次读取用两遍 hash 和文件元数据确认稳定；盘点所得 **380 个源文件**在准备及整套演练结束后再次核对，字节均未变化。私有路径与源 hash 只保留在进程内，不写入报告。

运行目录：`/private/tmp/swe-history-rehearsal-20261016-r2`。报告只提交聚合指标、匿名编号和工具源码摘要，未提交脱敏会话正文。该副本仍保留结构与长度信息，供本地维护验证使用。

## 验证过程

每个样本使用独立进程调用与维护 CLI 相同的存储方法，依次预览、显式迁移、校验和导出。Session 逐字段比较 agent 状态、消息及 turn；若原来未声明 `turn_states`，仅把缺省空字典作为等价结构。迁移后更新一个已有 turn 为 stopped（存在时），并新增一条合成 turn。Journal 比较全部事件、epoch 及 checkpoint 内容，再新增一条合成事实。

只有 events 的原始日志每次读取会临时生成 checkpoint ID/时间；演练仅在确认没有持久化 checkpoint 时，排除这两个新生成字段比较迁移前后状态。迁移实际保存的完整 checkpoint 随后与导出、旧版本读回结果精确比较，不忽略内容字段。

## 本地成本

| 指标 | 17 个 session | 4 份 journal |
| --- | ---: | ---: |
| 单样本迁移耗时范围 | 3.388–23.072 ms | 7.952–314.488 ms |
| 单样本导出耗时范围 | 2.856–26.068 ms | 3.851–12.005 ms |

| 单样本进程累计 RSS 峰值范围 | 117.5–143.2 MiB | 119.7–120.7 MiB |
| 迁移前文件数合计 | 17 | 8（含 4 个已创建锁文件） |
| 迁移后文件数合计 | 51 | 40 |
| 迁移前 payload 目录字节合计 | 1,052,527 | 37,382 |
| 迁移后 payload 目录字节合计 | 1,057,455 | 94,275 |

Python 峰值由 tracemalloc 统计单次方法调用期间的新增分配，调用前已有的对象不计入该数。RSS 是操作系统记录的独立样本进程累计高水位，包含导入、读回、比较等成本，不能把各阶段高水位当作该阶段独占内存，也不能相减推算优化收益。耗时是在启用 tracemalloc 的本地文件系统上逐样本单次测量，表中范围不是生产 P95 或并发吞吐。

文件数和目录大小在迁移完成、后续合成写入之前采样，只统计对应 sessions/dialog 树，包含锁和协议元数据，不包含报告、期望结果和导出目录。日志保留旧 events 文件并新增分段/根/元数据，本轮小样本迁移后占用变大符合保留历史和回退路径的设计。

**本批 session 的冷 turn 数全部为 0**，最大 journal 也未跨越分段上限。因此，本轮证明真实旧格式副本的兼容性和本地转换成本，不能证明长会话 RSS 或磁盘占用降低；最大的会话内容主要仍在 agent.memory 中。长历史收益需结合[此前合成基准](2026-10-15-memory-phase2-benchmark.md)评估，并在取得足够长的真实历史副本后补测。
