# 定时任务调度

定时任务的管理、触发、派发及追踪领域。

## Language

**定时任务回检**：新版 Agent 定时任务主执行成功后，按预设延迟自动执行的一次性指令。回检关联触发它的那一轮主执行，并在同一任务会话追加结果。
_Avoid_: 整轮成功后起算、批调度、手动创建的一次性任务

**迁移停旧入口**：在新版任务组接管前持久化停用旧文件定义并暂停已识别的旧平台定时器；不删除定时器、任务定义或原会话，不取消已开始的旧执行。
_Avoid_: 删除旧任务、暂停所有旧执行、同步回写旧定义表

**空闲回基准**：共享模型池连续两小时没有任务运行后回到基准容量，重新派发时按当前时段基准起步。容量已进入动态调节时，允许实际值低于基准。
_Avoid_: 基准作为所有派发的永久下限、没有执行反馈就重置

**Scheduler 确认时间**：Scheduler 观察到整轮执行终态并保存结论的时刻，不等于异步任务实际结束时间，也不等于主执行结束时间。
_Avoid_: 异步实际完成时间、主执行成功即整轮成功、将巡检间隔当成确认延迟保证

**前批优先派发**：模型池有空闲容量时，优先选取较早批次中当前可执行的任务；前批没有待派发候选时，后批可使用剩余容量。
_Avoid_: 严格逐批、整批串行、等待前批所有结果结束、保证早批一定先完成

**新版优先领取**：同一模型池内，当前可执行的新版任务优先使用空闲容量，旧队列只领取剩余名额；不抢占已领取或运行中的任务。
_Avoid_: 新版独占模型池、暂停旧调度、跨模型池排队、全局按新旧批次混合排序

**可执行时间区间**：任务允许实际开始执行的北京时间起止日期，包含首尾两天；父组统一配置，未配置不增加日期限制。
_Avoid_: 下次运行时间、通知时间、日期外提前执行后补跑

**次日预开**：提前准备明天生效任务的调度平台入口，同时保留今天仍有效的入口；不代表任务已获准提前执行。
_Avoid_: 次日提前执行、按明天日期关闭今天有效任务、平台入口开启等于业务允许运行

**日期维护**：统一调整日期对应的平台入口，关闭昨天及更早到期的任务；实际执行校验只决定本次能否运行，不承担入口开关。
_Avoid_: 执行触发顺带关停、等到维护关闭才算日期过期、提前关闭今天有效任务

**加急重跑**：已结束批次再次发起的异常重跑，优先争取空闲模型容量，不抢占运行中任务，也不增加并发上限。
_Avoid_: 绕过容量限制、重新创建平台批次、额外 Worker

**工作日执行准入**：自动任务依据原计划业务日判断是否允许进入执行；批次统一依据父任务的逻辑日期判断，不把批提前触发日当作业务日。它与可执行时间区间、人工启停分别约束任务。
_Avoid_: 普通周末等于所有非工作日、批内成员跨日重新过滤、手动执行套用自动工作日开关

**nW 工作日前移**：新版用户任务在当月第n日或之前选择最近的实际工作日，包含当天；n超过当月天数时从月末开始，若当月没有符合日期则该月不执行。
_Avoid_: 向后顺延、跨到上个月、月初无候选改为下个工作日、已错过日期自动补跑

**完成通知工作日过滤**：来源配置决定是否在原定通知的北京时间非工作日省略招呼通知；与任务是否允许非工作日执行独立，不删除运行结果或未读记录。
_Avoid_: 不通知等于未执行、允许假日执行等于必须通知、批提前运行日等于通知日
