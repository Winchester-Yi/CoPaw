# 03 MySQL 投影与 API

Status: ready-for-agent
Type: task
Blocked by: 01

## 目标

将请求级事实投影到现有观测数据链路，并通过授权 API 为 Run 摘要和请求详情提供可核对的数据。 [首批 Spec](../spec.md)

## 验收

- [ ] 用唯一逻辑调用计算 `llm_calls`，用唯一请求尝试计算请求数与已获取用量。验证重复投影、重试、部分覆盖、真实零值和历史 `null`。
- [ ] 请求详情暴露请求序号、请求模型、实际模型及来源、流式模式、结束原因、终态、时延和已知 Token。按现有 Source 和租户授权校验。
- [ ] 只有结束事件时投影为 `partial`，迟到开始事件可补齐质量。字段类型错误和单行写入失败有隔离验证，后续有效事件仍可入库。
- [ ] 在隔离 MySQL 验证生产 SSE、重试和取消的数据从 JSONL 投影到授权 API。
