# 01 模型请求事实采集

Status: ready-for-agent
Type: task

## 目标

在 OpenAI 兼容适配器和项目可见的 Provider 请求边界记录每次真实请求。为逻辑调用、请求尝试和重试关系保留独立身份。 [首批 Spec](../spec.md) · [生产 SSE 样例](../../agent-observability/issues/05-model-call-observability.md#生产-openai-兼容流式响应样例)

## 验收

- [ ] 实际模型和结束原因取自可信响应字段。生产样例的结束帧与纯 Usage 帧合并到同一请求，得到输入 333、输出 11。
- [ ] 验证非流式、空帧、纯 Usage 帧、正常结束、失败和取消。失败与取消保留已获取的累计用量及首输出时延。
- [ ] 同任务交错打开两条流、跨任务消费以及消费前关闭时，请求身份、重试关联和终态均准确。
- [ ] 验证重试用量逐次归属、真实零值和缺失用量。观测 JSONL 通过元数据白名单检查，原业务响应及异常语义通过回归。
