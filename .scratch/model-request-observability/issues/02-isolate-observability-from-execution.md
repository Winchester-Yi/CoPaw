# 02 采集与业务隔离

Status: resolved
Type: task

## 目标

会话准入和聊天执行只依赖业务状态。将正文证据恢复的初始化、工作区登记与重试放到后台。 [首批 Spec](../spec.md) · [独立采集 ADR](../../../docs/adr/0047-independent-agent-observability-uses-metadata-logs.md)

## 验收

- [x] 采集开关两种状态下，同一终态消息的重复提交、重连和显式重执行业务结果一致，观测 Run 按实际受理结算。
- [x] 用阻塞或失败的观测库登记验证请求立即继续，模型元数据仍可采集。验证后台重试与登记成功后新证据的关联，已持久化可验证信封仍可恢复。
- [x] 后台 SubAgent 转发走事件契约和元数据白名单。补偿终态以持久化业务结果为依据，缺少可信终态时保持未知。

## 验证

- 准入回归以业务 Turn 身份区分重复提交与重执行，分别在采集开关两种状态下验证持久化结果。
- 使用模拟数据库阻塞、事务提交与登记失败覆盖后台重试。等待登记时模型仍完成并产出 Span，证据标为未留存。登记成功后产生可验签的证据信封。
- 真实 worker 子进程的结束事件经父进程验证和转发。测试同时验证普通 stdout JSON 不会转发，补偿终态以持久化记录为准。

验证记录见[测试报告](../test-report.md)。
